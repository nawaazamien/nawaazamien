## What I build

- **Full-stack products**: React, TypeScript and Vite front ends on PostgreSQL and Supabase back ends.
- **Multi-tenant SaaS**: tenancy, role-based access, row-level security and auditable data.
- **Backend and data-heavy systems**: ledgers, ingestion pipelines, idempotent workflows and concurrency control.
- **Automation and research tooling**: local pipelines, and backtesting infrastructure built around reproducibility.
- **Interactive systems**: gameplay and simulation systems in Godot.
